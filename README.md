# E2E Test Automation Framework for Petstore 'pet' API

## Setup
- Java 21, Gradle 8 required
- See `gradle.properties` for dependency versions

## Usage
- Run `gradle build` to compile
- Run `gradle test` to execute all tests

## Structure
- Source: `src/main/java/com/epam/ai/`
- Tests: `src/test/java/com/epam/ai/`

## Features
- Contract and integration tests for Petstore 'pet' endpoints
- Models, service, Retrofit client for API
- Error handling and edge case coverage
